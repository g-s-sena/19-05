# Documentação do Projeto: Portal de Prestação de Serviços

Este repositório contém a entrega referente à implementação da API RESTful para o recurso de "Serviços" (Backend) e os protótipos de alta fidelidade para o fluxo de "Cadastro de Prestador de Serviço" (Frontend).

## 1. Tecnologias Adotadas

* **Ambiente de Execução:** Node.js
* **Framework Web:** Express
* **Linguagem:** TypeScript
* **Validação de Dados e DTOs:** Zod
* **Execução em Desenvolvimento:** tsx

## 2. Instruções de Execução

### Pré-requisitos
Certifique-se de ter o Node.js previamente instalado em seu ambiente local.

### Inicialização do Servidor
1. Abra o terminal de comando na raiz do diretório do projeto.
2. Realize a instalação das dependências executando:

   '''bash
   npm install

   npm run dev

O serviço estará acessível através do endereço local: http://localhost:3000
